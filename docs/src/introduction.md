# illbethejudgeofthat

illbethejudgeofthat is a pro se legal case builder — it structures legal arguments, tracks case evidence, and generates court-ready documents for self-represented litigants. A 10-stage Rust pipeline turns a Google Takeout mbox archive into a numbered PDF exhibit book, Motion to Modify Custody, Memorandum in Support, and filled court forms. Runs entirely on-device with no cloud dependency. Public domain (Unlicense).
